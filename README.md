# Practical Machine Learning: MNIST Fine-Tuning with ResNet18

This repository contains the training pipeline to fine-tune a pre-trained ResNet18 Convolutional Neural Network on the MNIST dataset.

* **Test the App (Live Demo):** [Hugging Face Space](https://huggingface.co/spaces/joaoalexandre14/mnist-resnet18-classifier/tree/main)

## 📦 Project Structure
The deployment of this model was done using **Gradio** and is hosted on **Hugging Face Spaces**. 
The application allows users to draw a digit (0-9) on a virtual pad or upload an image to get the estimated probabilities for each class.
